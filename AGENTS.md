# poh-sprint-report — правила для агентов

- Jira — только чтение: в `jira.py` есть только GET, другого метода не добавлять.
- Токены не печатать и не писать на диск: дамп `--record` содержит путь, параметры и тело ответа, без заголовков.
- Без сторонних пакетов: stdlib Python 3.10+, печать — внешним Chrome.
- Реальные данные Jira (снимки, PDF, `data.json`) в репозиторий не коммитить; примеры и тесты — только на `demo.py`
  (вымышленные люди, команда «Альфа», ключи ALF-*).
- Перед коммитом: `python3 -m unittest discover -s tests` и `python3 -m sprint_report demo --html-only`.
- Новая цифра в отчёте — с формулой в README («Что в отчёте» / «Как считается»).
